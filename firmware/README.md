# Firmware

Diretório reservado ao código efetivamente utilizado na miniestação de Potim em 2025.

**Situação:** o arquivo original do Arduino não foi fornecido para esta versão. Não há um programa disponível para compilar ou carregar na placa.

Ao publicar o código, substituir senhas de Wi-Fi e chaves de API por placeholders. A documentação pública deve explicar como configurar esses valores localmente, sem conter credenciais reais.

O código do artigo de referência não deve ser apresentado como se fosse o firmware original de Potim. Veja as [fontes](../references/fontes.md), o [esquema de ligações](../hardware/esquema-ligacoes.md) e a [comunicação com o ThingSpeak](../docs/comunicacao-thingspeak.md).
