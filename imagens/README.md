# Imagens e registros visuais

Este diretório organiza a documentação visual da **Estação Meteorológica Educacional de Potim**, desenvolvida em 2025 no Clube de Robótica do município de Potim/SP.

Os registros disponíveis documentam diferentes etapas do projeto: construção do protótipo, desenvolvimento dos sensores de vento, atividades práticas com estudantes, testes realizados na escola, visualização dos dados e divulgação do projeto.

> **Observação:** parte dos arquivos históricos foi adicionada originalmente na raiz do repositório. Este README funciona como índice para facilitar a consulta sem alterar os caminhos dos arquivos já publicados.

## Uso das imagens

Os registros visuais têm finalidade de documentação histórica, educacional e técnica do projeto.

Ao adicionar novas imagens, registrar sempre que possível:

- contexto da fotografia;
- etapa do desenvolvimento;
- data ou período aproximado;
- autoria;
- autorização de uso quando houver pessoas identificáveis.

Imagens e arquivos de projetos externos de terceiros devem permanecer claramente identificados como materiais externos e sujeitos às respectivas licenças.
