# Estado do projeto e possíveis próximos passos

[Voltar ao README](../README.md)

O projeto foi interrompido devido à descontinuidade do Clube de Robótica de Potim/SP. Este documento separa o histórico informado, as lacunas de documentação e sugestões para uma eventual continuidade. Não representa um compromisso de retomada.

## Histórico informado

| Item | Situação |
| --- | --- |
| Atividade educacional em 2025 | Desenvolvimento de uma miniestação meteorológica no Clube de Robótica de Potim/SP. |
| Componentes e serviços utilizados | Arduino Nano, DHT11, sensor de pressão, ESP8266, Wi-Fi e ThingSpeak. |
| Alimentação e estrutura | Uso de baterias, painel solar e tubos de PVC; especificações ainda não fornecidas. |
| Sensores de vento | Em desenvolvimento pelos alunos com impressão 3D e componentes de baixo custo; conclusão não informada. |
| Comparação com estação profissional | Planejada a partir de uma estação instalada em escola municipal; não finalizada. |
| INPE Portas Abertas 2025 | Projeto apresentado e exposto em São José dos Campos/SP junto ao então Projeto Educação, atual Programa Educação. |
| Continuidade | Interrompida com a descontinuidade do Clube de Robótica. |
