## Papel no projeto

ESP8266, Wi-Fi e ThingSpeak integraram a atividade de aquisição, transmissão e visualização de dados ambientais. O projeto teve caráter educacional e abordou conceitos de Internet das Coisas (IoT).

O caminho conceitual dos dados está descrito na [arquitetura](arquitetura.md). A implementação exata deve ser recuperada do firmware original: não foram informados protocolo, comandos, bibliotecas, configuração de canal ou cadência de envio.
